## Reference TCC #1: ICMC/USP CeMEAI - MBA em Ciências de Dados

**Title**: Data science for determining similarity between oil well logs: an approach using Self-Organizing Maps

**Author**: Cleyton de Carvalho Carneiro

**Institution**: Instituto de Ciências Matemáticas e de Computação (ICMC), Universidade de São Paulo (USP)

**Program**: MBA em Ciências de Dados (MBA in Data Science)

**Year**: 2021

**Pages**: 52 pages

**Format**: Monografia (Monograph)

**URL**: https://sites.icmc.usp.br/apneto/MBA/TCC_MBA_2021_Cleyton.pdf

### Structural Elements (Based on Citation)

| Element | Description |
|---------|-------------|
| **Format Type** | Monografia (Traditional monograph format) |
| **Length** | 52 pages (typical for MBA TCCs: 40-80 pages) |
| **Method** | Self-Organizing Maps (SOM) - Unsupervised Machine Learning |
| **Domain** | Oil well log analysis - Applied data science |
| **Data Source** | Oil well logs (industry data) |
| **Techniques** | Dynamic Time Warping (DTW), Self-Organizing Maps |

### Implied Structure (Standard USP ICMC MBA Format)

Based on the CeMEAI ICMC/USP MBA program guidelines and this example:

```
1. CAPA (Cover)
2. FOLHA DE ROSTO (Title Page)
3. FICHA CATALOGRÁFICA (Catalog Card)
4. RESUMO (Abstract in Portuguese) - 250 words
5. ABSTRACT (Abstract in English) - 250 words
6. LISTA DE FIGURAS (List of Figures)
7. LISTA DE TABELAS (List of Tables)
8. LISTA DE ABREVIATURAS (List of Abbreviations)
9. SUMÁRIO (Table of Contents)

10. INTRODUÇÃO (Introduction)
    - Contextualização
    - Problema de pesquisa
    - Objetivos
    - Justificativa
    - Delimitação

11. REVISÃO DA LITERATURA (Literature Review) - Optional but recommended
    - Fundamentação teórica
    - Trabalhos relacionados

12. MATERIAL E MÉTODOS (Material and Methods)
    - Descrição dos dados
    - Pré-processamento
    - Métodos analíticos (SOM, DTW)
    - Ferramentas utilizadas

13. RESULTADOS E DISCUSSÃO (Results and Discussion)
    - Apresentação dos resultados
    - Análise e interpretação
    - Discussão dos achados

14. CONCLUSÃO (Conclusion)
    - Considerações finais
    - Limitações
    - Sugestões para trabalhos futuros

15. REFERÊNCIAS (References)
    - Formato ABNT NBR 6023

16. APÊNDICES (Appendices) - If applicable
17. ANEXOS (Annexes) - If applicable
```

**Program**: MBA em Data Science e Analytics

**Institution**: Escola Superior de Agricultura "Luiz de Queiroz" (ESALQ), USP

**Format**: Projeto de Pesquisa (Research Project) + Resultados Preliminares

### Document Templates Available

From the user's TCC folder:

1. **Template Projeto de Pesquisa.docx** (3a-etapa/)
   - Phase: 3rd stage (Research Project)
   - Format: Structured research proposal
   
2. **Template Resultados Preliminares_PT.docx** (4a-etapa/)
   - Phase: 4th stage (Preliminary Results)
   - Format: Results and preliminary analysis

### ESALQ MBA TCC Structure (From Templates)

#### Phase 1: Research Project (Projeto de Pesquisa)

```
1. IDENTIFICAÇÃO
   - Título
   - Aluno
   - Orientador

2. INTRODUÇÃO
   - Contexto e justificativa
   - Problema de pesquisa
   - Objetivos (geral e específicos)
   - Hipóteses (se aplicável)

3. REVISÃO DE LITERATURA
   - Fundamentação teórica
   - Estado da arte

4. MATERIAL E MÉTODOS
   - Dados (fontes, período, variáveis)
   - Métodos estatísticos/analíticos
   - Ferramentas

5. CRONOGRAMA
   - Etapas e datas previstas

6. REFERÊNCIAS
```

#### Phase 2: Final TCC (Trabalho de Conclusão)

```
1. Elementos Pré-Textuais

   - Folha de rosto

   - Resumo (Português)
   - Abstract (Inglês)
   - Listas (figuras, tabelas, abreviações)
   - Sumário

2. INTRODUÇÃO

3. REVISÃO DA LITERATURA (opcional)

4. MATERIAL E MÉTODOS

5. RESULTADOS E DISCUSSÃO

6. CONCLUSÃO

7. REFERÊNCIAS

8. Elementos Pós-Textuais (Apêndices, Anexos)
```

## Abstract Structure (Resumo/Abstract)

### 5-Sentence Formula (Recommended)

1. **Context**: General introduction to the research area
2. **Problem**: Specific issue or gap addressed
3. **Method**: Approach used to address the problem
4. **Results**: Key findings (with key statistics)
5. **Implications**: Significance and applications

### Example Template (Portuguese)

```
A presente pesquisa investiga [tema] no contexto de [contexto específico]. 
O problema abordado é [descrição do problema], considerando que [justificativa]. 
Utilizou-se [métodos principais] para analisar [dados/amostra]. 
Os resultados indicam [achado principal], com [estatística chave]. 
Conclui-se que [implicação principal], sugerindo [aplicação ou trabalho futuro].
```

### Example Template (English)

```
This research investigates [topic] in the context of [specific context]. 
The problem addressed is [problem description], considering that [justification]. 
[Main methods] were used to analyze [data/sample]. 
Results indicate [main finding], with [key statistic]. 
We conclude that [main implication], suggesting [application or future work].
```

## Application to This Thesis

### Recommended Structure for "Public Spending Efficiency, Compliance Risk, and Anomaly Detection in Brazil"

Based on USP MBA TCC patterns:

```
1. CAPA + FOLHA DE ROSTO
2. FICHA CATALOGRÁFICA
3. RESUMO (250 words, pt-BR)
4. ABSTRACT (250 words, en)
5. LISTA DE FIGURAS
6. LISTA DE TABELAS
7. SUMÁRIO

8. INTRODUÇÃO (5-8 páginas)
   - Contexto: Compliance público e eficiência de gastos
   - Problema: Relação entre transferências e sanções
   - Objetivos: Análise correlacional e preditiva
   - Justificativa: Relevância para governança
   - Delimitação: 5.570 municípios, 2010-2022

9. MATERIAL E MÉTODOS (10-15 páginas)
   - Fontes: IBGE, Portal Transparência, CGU
   - Arquitetura: Bronze/Silver/Gold
   - Métodos: Estatística descritiva, Regressão, ML, Clustering
   - Ferramentas: Python, pandas, scikit-learn, AWS

10. RESULTADOS E DISCUSSÃO (15-20 páginas)
    - Análise descritiva (sanções por região)
    - Modelagem estatística (correlações, regressão)
    - Machine Learning (ElasticNet, Random Forest)
    - Clustering (K-means de municípios)
    - Interpretação: Capacidade de detecção vs. conduta

11. CONCLUSÃO (3-5 páginas)
    - Síntese dos achados
    - Limitações (n=27 estados, corte transversal)
    - Implicações para políticas públicas
    - Trabalhos futuros

12. REFERÊNCIAS
    - 40-60 referências (ABNT NBR 6023)

13. APÊNDICES (se necessário)
    - Códigos
    - Tabelas detalhadas
```

## Key Takeaways

1. **Follow the template**: Use the ESALQ Template Resultados Preliminares as base
2. **Bilingual abstracts**: Both Portuguese and English required
3. **Method focus**: Heavy emphasis on Material e Métodos (20-25% of pages)
4. **Results emphasis**: Results and Discussion is the largest section (30-35%)
5. **Practical application**: USP MBA TCCs favor applied data science over pure theory
6. **Reproducibility**: Code and data documentation increasingly important
7. **Course alignment**: Reference MBA course materials in methodology
